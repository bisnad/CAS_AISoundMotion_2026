————————————————————————
Installation
————————————————————————

For MacOS
- Open the terminal
- Type "sh install_MacOS.sh"
- Download ALL the models (not LORA) from here: https://huggingface.co/hugggof/vampnet/tree/main
- Move them to the folder models/unloop
- Everything is stored locally below the main folder.
- Done.


For Windows 11
- Run install_Windows.bat"
- Download ALL the models (not LORA) from here: https://huggingface.co/hugggof/vampnet/tree/main
- Move them to the folder models/unloop
- Everything is stored locally below the main folder.
- Done.


————————————————————————
Run in the browser
————————————————————————

For MacOS
- Open the terminal
- Type "sh run_app_MacOS.sh"
- When loaded, find the URL in the terminal: http://127.0.0.1:7860
- Open your preferred browser to this URL: http://127.0.0.1:7860
- Done.


For Windows 11
- Run "run_app_Windows.bat"
- When loaded, find the URL in the terminal: http://127.0.0.1:7860
- Open your preferred browser to this URL: http://127.0.0.1:7860
- Done.
