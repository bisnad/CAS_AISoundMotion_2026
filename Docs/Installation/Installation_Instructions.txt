CAS AI for Creative Practices
Installation Guide for Module 3: AI for Sound and Module 5: AI for Motion

This guide prepares your computer to run the main course examples.

IMPORTANT
- Follow the steps in the order shown.
- Complete the verification check at the end of each installation step before moving on.
- Use PowerShell on Windows and Terminal on macOS.
- Copy commands exactly, including punctuation.
- You need an internet connection and may need administrator permission on your computer.
- Do not share your Hugging Face access token with anyone.
- macOS support: Only Apple computers with Apple silicon are supported. Intel-based Macs are not supported by this course installation.

======================================================================
1. BEFORE YOU START
======================================================================

Supported computers:

- Windows: Windows computers are supported. Use the appropriate course installation script depending on whether the computer has an NVIDIA GPU.
- macOS: Only Macs with Apple silicon are supported, for example M1, M2, M3, or later chips. Intel-based Macs are not supported.

How to check your Mac:

1. Click the Apple menu in the top-left corner of the screen.
2. Choose About This Mac.
3. Look for "Chip". It should say Apple M1, Apple M2, Apple M3, or a later Apple chip.
4. If it says "Processor" followed by Intel, your Mac is not supported by this installation guide.

You will install three tools before downloading the course material:

1. A compilation environment: lets Python install components that need to be built on your computer.
2. Git: downloads and updates course files.
3. uv: installs and runs the Python environments used by the examples.

Terminology:
- PowerShell: the command-line application used in this guide on Windows.
- Terminal: the command-line application used in this guide on macOS.
- Command: a line of text that you paste or type into PowerShell or Terminal, then press Enter.
- Repository: a course folder downloaded from GitHub.
- Script: a file that starts an installation or course example. Windows scripts end in .bat; macOS scripts end in .sh.

2. INSTALL A COMPILATION ENVIRONMENT
======================================================================

Some Python packages used in the course need compiler tools during installation. On macOS, this step also installs Git.

---------------------------------------------------------------------
2A. MACOS WITH APPLE SILICON ONLY: INSTALL XCODE COMMAND LINE TOOLS
---------------------------------------------------------------------

This section applies only to supported Macs with Apple silicon. Intel Macs are not supported.

1. Open Terminal.
2. Run:

xcode-select --install

3. A macOS dialog appears. Choose Install.
4. Accept any licence or permission requests and wait for the installation to finish.
5. Close Terminal and open a new Terminal window.

Verify the compiler and Git:

Run these commands one at a time:

clang --version
make --version
git --version

Success: Each command shows version information rather than an error.

---------------------------------------------------------------------
2B. WINDOWS: INSTALL VISUAL STUDIO BUILD TOOLS
---------------------------------------------------------------------

1. Open PowerShell.
2. Copy the complete command below into PowerShell. It is one command; the backtick character (`) continues it on the next line.

winget install --exact --id Microsoft.VisualStudio.2022.BuildTools `
  --override "--passive --wait --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"

3. If Windows shows a UAC permission window, choose Yes.
4. Wait for the installation to finish. It may take some time.
5. Close every open PowerShell window.

Verify the compiler:

1. Open the Start menu.
2. Search for and open:

x64 Native Tools Command Prompt for VS 2022

3. Run:

cl

Success: Output begins with text similar to:

Microsoft (R) C/C++ Optimizing Compiler Version ...

If you see this text, the compiler is available.

3. INSTALL GIT AND GIT LFS
======================================================================

Git downloads the course repositories. Git LFS (Large File Storage) downloads large files such as audio, video, motion-capture data, and model weights.

---------------------------------------------------------------------
3A. MACOS WITH APPLE SILICON ONLY: INSTALL GIT LFS
---------------------------------------------------------------------

Git was installed in Section 2 with the Xcode Command Line Tools. This section installs Git LFS.

1. Open a web browser.
2. Go to:

https://git-lfs.com/

3. Download the Apple Silicon version of Git LFS for macOS.
4. Open the downloaded ZIP file to unpack it.
5. Open Terminal.
6. Run:

cd ~/Downloads/git-lfs-*
sudo ./install.sh

7. Enter your Mac password if requested. 

Verify Git LFS:

Open a new Terminal window and run:

git lfs version

Success: You see a Git LFS version number.

---------------------------------------------------------------------
3B. WINDOWS: INSTALL GIT
---------------------------------------------------------------------

1. Open the Start menu.
2. Search for PowerShell.
3. Open PowerShell.
4. Run this command:

winget install --exact --id Git.Git --source winget

5. If Windows asks for permission through a User Account Control (UAC) window, choose Yes.
6. When the installation finishes, close PowerShell.

Verify Git:

1. Open a new PowerShell window.
2. Run:

git --version

Success: You see a version number, for example, "git version 2.x.x".

---------------------------------------------------------------------
3C. WINDOWS: INSTALL GIT LFS
---------------------------------------------------------------------

1. Open a web browser.
2. Go to:

https://git-lfs.com/

3. Download and install the Windows version of Git LFS.
4. When installation is complete, open a new PowerShell window.
5. Run:

git lfs install

Verify Git LFS:

Run:

git lfs version

Success: You see a Git LFS version number.

======================================================================
4. INSTALL UV
======================================================================

uv manages the Python environments and packages used by the course examples.

---------------------------------------------------------------------
4A. MACOS WITH APPLE SILICON ONLY: INSTALL UV
---------------------------------------------------------------------

1. Open Terminal.
2. Run:

curl -LsSf https://astral.sh/uv/install.sh | sh

3. When the installation finishes, close Terminal.
4. Open a new Terminal window.

Verify uv:

uv --version

Success: You see a uv version number.

If the command says "uv: command not found", close Terminal completely, open it again.

---------------------------------------------------------------------
4A. WINDOWS: INSTALL UV
---------------------------------------------------------------------

1. Open PowerShell.
2. Run:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

3. When the installation finishes, close PowerShell.
4. Open a new PowerShell window.

Verify uv:

uv --version

Success: You see a uv version number.

5. DOWNLOAD THE COURSE REPOSITORIES
======================================================================

There are two course repositories:

- CAS_AISoundMotion_2026: REQUIRED. It contains source code, examples, and installation scripts.
- CAS_AISoundMotion_Data_2026: OPTIONAL. It contains additional course data, including video, audio, motion-capture files, and model weights. This data repository can be large.

Only downloading CAS_AISoundMotion_2026 is mandatory; downloading CAS_AISoundMotion_Data_2026 is optional.

---------------------------------------------------------------------
5A. CREATE A COURSE FOLDER
---------------------------------------------------------------------

1. Open Finder on macOS or File Explorer on Windows.
2. Choose a location that is easy to find, such as Documents.
3. Create a new folder, for example:

CAS_AI_Course

4. Open this folder and copy its path.

Tips for finding the path:
- macOS: right-click the folder while holding Option, then choose "Copy ... as Pathname" if 
- Windows: click the address bar in File Explorer and copy the displayed path.available. You can also type "cd " in Terminal and drag the folder into the Terminal window.

---------------------------------------------------------------------
5B. CLONE THE REQUIRED COURSE REPOSITORY
---------------------------------------------------------------------

1. Open Terminal on macOS or PowerShell on Windows.
2. Move to the course folder you created. Replace <path-to-your-course-folder> with the actual folder path.

cd <path-to-your-course-folder>

Example on macOS:

cd ~/Documents/CAS_AI_Course

Example on Windows:

cd C:\Users\YourName\Documents\CAS_AI_Course

3. Download the required course code repository:

git clone https://github.com/bisnad/CAS_AISoundMotion_2026.git

4. Wait for the command to finish. Do not close the window while files are downloading.

Check your work:

Your course folder should now contain this folder:

CAS_AISoundMotion_2026

---------------------------------------------------------------------
5C. OPTIONAL: CLONE THE COURSE DATA REPOSITORY
---------------------------------------------------------------------

1. Make sure Terminal or PowerShell is still in your course folder. If necessary, run:

cd <path-to-your-course-folder>

2. Download the optional data repository:

git clone https://github.com/bisnad/CAS_AISoundMotion_Data_2026.git

3. Wait for the command to finish. Do not close the window while files are downloading.

Check your work:

Your course folder should now also contain:

CAS_AISoundMotion_Data_2026

If the download appears to skip large files or shows Git LFS errors, repeat the Git LFS installation in Section 3.

---------------------------------------------------------------------
5D. MACOS ONLY: OPEN .SH FILES IN TERMINAL
---------------------------------------------------------------------

macOS shell scripts have the extension .sh. Configure Finder to open them in Terminal:

1. In Finder, open the CAS_AISoundMotion_2026 folder.
2. Navigate to this example file:

Installers/run_installation_macos-cpu.sh

3. Select the file and press Command + I to open Get Info.
4. Under "Open with", select Terminal.
5. Click "Change All..." if you want all .sh files to open in Terminal.
6. Confirm the change if macOS asks.

6. INSTALL THE COURSE PYTHON ENVIRONMENTS
======================================================================

The installation script prepares each example folder for your operating system. It copies the correct uv project files (pyproject.toml) into the relevant folders.

---------------------------------------------------------------------
6A. MACOS WITH APPLE SILICON: RUN THE INSTALLATION SCRIPT
---------------------------------------------------------------------

1. In Finder, open:

CAS_AISoundMotion_2026/Installers

2. Double-click:

run_installation_macos-cpu.sh

3. Terminal opens and runs the script.
4. Wait until the script finishes. 

---------------------------------------------------------------------
6B. WINDOWS: RUN THE INSTALLATION SCRIPT
---------------------------------------------------------------------

First determine whether your computer has an NVIDIA graphics card (GPU).

1. Right-click the Start button and choose Device Manager.
2. Expand "Display adapters".
3. If an entry includes "NVIDIA", use the cu126 script. Otherwise, use the cpu script.

- If your Windows PC has an NVIDIA GPU, use:

CAS_AISoundMotion_2026/Installers/run_installation_windows-cu126.bat

- If your Windows PC has no NVIDIA GPU, use:

CAS_AISoundMotion_2026/Installers/run_installation_windows-cpu.bat

Then:

1. Open File Explorer.
2. Navigate to:

CAS_AISoundMotion_2026/Installers

3. Double-click the appropriate .bat file.
4. A command window opens. Wait until it finishes.

If Windows displays a security warning, check that the file is inside the downloaded CAS_AISoundMotion_2026 folder before choosing to run it.

8. SET UP VISUAL STUDIO CODE
======================================================================

Visual Studio Code may ask whether you trust the course folders. Trust is needed so that the editor can run project features and scripts.

1. Open Visual Studio Code.
2. Open one of the example folders from the course repository.
3. Open the Command Palette:
   - macOS: Command + Shift + P
   - Windows: Ctrl + Shift + P
4. Type:

Workspaces: Manage Workspace Trust

5. Select the command from the list.
6. Choose Trust.
7. If Visual Studio Code asks whether to trust all folders in the downloaded GitHub repository, confirm only if the repository was downloaded from the official course link in this guide.

9. GAIN ACCESS TO HUGGING FACE MODELS
======================================================================

Some course examples download models from Hugging Face. Several of these models are gated, which means you must create an account, accept the model conditions, and authenticate on your computer before the examples can download them.

---------------------------------------------------------------------
9A. CREATE A HUGGING FACE ACCOUNT
---------------------------------------------------------------------

1. Open a web browser and go to:

https://huggingface.co/

2. Select Sign Up.
3. Create an account using your email address and a username.
4. Verify your email address.
5. Sign in in the web browser.

---------------------------------------------------------------------
9B. REQUEST ACCESS TO STABLE AUDIO OPEN 1.0
---------------------------------------------------------------------

1. While signed in, open:

https://huggingface.co/stabilityai/stable-audio-open-1.0

2. Read the displayed licence and access conditions.
3. Complete any required fields.
4. Select the access button. Depending on the page, it may be named:

Agree and access repository
Request access
Accept and continue

---------------------------------------------------------------------
9C. REQUEST ACCESS TO STABLE AUDIO 3 SMALL-SFX
---------------------------------------------------------------------

1. While signed in, open:

https://huggingface.co/stabilityai/stable-audio-3-small-sfx

2. Read the displayed licence and access conditions.
3. Complete any required fields.
4. Select the access button, which may be named:

Agree and access repository
Request access
Accept and continue

---------------------------------------------------------------------
9D. CREATE A READ TOKEN
---------------------------------------------------------------------

A token is a private credential. It allows software on your computer to access models using your Hugging Face account.

1. Go to:

https://huggingface.co/settings/tokens

2. Select New token.
3. Give the token a meaningful name, for example:

CAS AI course laptop

4. Choose a token with read-only access.
5. Select Generate token.
6. Copy the token and store it somewhere safe.

Security rules:
- Treat the token like a password.
- Never share it in chat, email, screenshots, or course submissions.
- Do not add it to GitHub or other public repositories.

---------------------------------------------------------------------
9E. LOG IN FROM YOUR COMPUTER
---------------------------------------------------------------------

1. Open Terminal on macOS or PowerShell on Windows.
2. Move into this folder. Replace <path-to-your-course-folder> with your actual path:

cd <path-to-your-course-folder>/CAS_AISoundMotion_2026/AI_Sound

3. Start Hugging Face login:

uv run hf auth login

4. When prompted, paste your personal read token and press Enter.
5. Check that login worked:

uv run hf auth whoami

Success: The command displays your Hugging Face username.
