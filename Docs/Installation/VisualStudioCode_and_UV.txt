How to Get Visual Studio Code to work with Python and UV:

1. Install Microsoft version of Python:
1.1. Open Extensions: Cmd + Shift + X
1.2. Type: Python
1.3. Click: Install

2. Grant Permission to Project Folder
2.1. Open Project Folder
2.2. Open Command Palette: Cmd + Shift + P
2.3. Type: Workspaces: Manage Workspace Trust
2.4. Click: Trust

3. Select Python Interpreter for Project Folder
3.1. Open Project Folder
3.2. Open Command Palette: Cmd + Shift + P
3.3. Type: Python: Select Interpreter
3.4. Chose: Enter interpreter path
3.5. Navigate to python in .venv environment (For MacOS, make hidden folders/files visible with ⌘ Command + ⇧ Shift + . (period))

4. Change Multi-Line Code Evalation Behaviour (MacOS only)
4.1. In MacOS Finder, Edit/Create file settings.json within .vscode folder

2. For each code example:
2.1. Open Folder containing for one of the examples
2.2. Add the Line: "python.REPL.sendToNativeREPL": true,
2.3. Add the Line: "python.terminal.executeInFileDir": true
